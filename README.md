# TMatch

I wrote this game in 2012, inspired by a game called [Triple Town](https://spryfox.com/our-games/tripletown/) by spryfox,
using a tileset by [Dan Cook](https://lostgarden.com/2007/05/12/dancs-miraculously-flexible-game-prototyping-tiles/).

Now I'm going to rewrite it entirely using Flutter so it can be played on
modern devices.
