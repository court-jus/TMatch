# Game over

If the "Next" tile cannot be placed nor stashed, it's game over. The key of course is a special case because it erases a tile that is already placed, it can always be stashed.

If the "Next" tile cannot be placed but a stashed tile can be placed, the game is not over, the player can still swap this stash and play with that tile.

When matching three tiles and replacing them with a "higher" one, if a person is on a tile that has been removed, it will try to move immediately to avoid ending on an empty tile (Water), if that is not possible because no tile is reachable, that little person drowns. If the last person drowns, that's game over.

When the game is over, the reason is explained to the player.
